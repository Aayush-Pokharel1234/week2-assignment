# Personal Portfolio Website

## Project Overview

This project is a single-page personal portfolio website developed using **semantic HTML5**. The purpose of the project is to demonstrate the use of meaningful HTML5 elements to organize personal information, technical skills, projects, and contact information.

The website uses only browser-default HTML rendering. **No CSS, external stylesheet, or inline styling is used**, as required by the assignment.

## Features

The portfolio includes the following sections:

* Personal introduction and biography
* Profile image with alternative text
* Technical skills using a description list
* Two project sections using semantic `<article>` elements
* Internal navigation links
* Accessible contact form
* Name, Email, and Message fields
* Submit button
* Public GitHub repository links
* Semantic HTML5 structure

## Technologies Used

* HTML5
* GitHub
* Web Browser
* W3C HTML Validator

No CSS or JavaScript is used in this project.

## Semantic HTML5 Elements

The following semantic HTML5 elements are used:

* `<header>` - Contains the main title and navigation.
* `<nav>` - Contains the primary navigation links.
* `<main>` - Contains the main content of the portfolio.
* `<section>` - Organizes the portfolio into different sections.
* `<article>` - Represents individual project modules.
* `<footer>` - Contains the copyright information.

## Portfolio Sections

### About Me

The About section provides a brief biography and displays the profile image.

### Technical Skills

The Skills section uses a description list (`<dl>`) to present technical skills and their descriptions.

### Projects

The Projects section contains two independent project modules using `<article>` elements.

### Contact

The Contact section contains an accessible form with:

* Name
* Email
* Message
* Submit button

Each form field has an explicitly associated `<label>`.

## How to Run the Project

1. Download or clone this repository.
2. Open the `aayush-personal-portfolio` folder.
3. Make sure `index.html` and the `images` folder are in the correct locations.
4. Open `index.html` in a web browser.
5. The portfolio will be displayed using the browser's default HTML layout.
